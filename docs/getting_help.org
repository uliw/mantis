* Getting help
Please raise an issue on https://github.com/uliw/mantis/issues and include the output of the following commands:
#+BEGIN_SRC jupyter-python
python --version   
python -c "import importlib.metadata; print(importlib.metadata.version('mantis-rtm'))"
#+END_SRC
As well as information on whether you installed Mantis via GitHub, pip or conda
